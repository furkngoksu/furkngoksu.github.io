LLM-based recommendation

A generative movie recommender built on Llama 3, and a study of how the design of its fine-tuning data affects recommendation quality and demographic sensitivity.

Context
Graduation project, ITU
Published
EARL Workshop at CIKM 2026
Paper
arXiv:2611.03113

Results

12.47%HR@10, up from 7.47%
3,883movies in the catalog
100%of recommendations stay in the catalog

Problem

A language model can recommend movies by writing their titles, but it can also write titles that don't exist. Choices made while preparing the training data, such as prompt wording or how users are sampled, also change what the model learns and which users it serves well.

Approach

  • Llama-3-8B-Instruct fine-tuned with LoRA on MovieLens-1M user histories.
  • Each recommended title is wrapped in special tokens. While the model writes a title, decoding follows a prefix tree built from the catalog, so every output is a real movie.
  • Models trained with different data mixes, prompt templates, title formats and group-balanced sampling, then compared on accuracy and on differences between user groups.
