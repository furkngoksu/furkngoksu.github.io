GRADUATION PROJECT AND PAPER

LLM-based movie recommendation

A recommender built on Llama 3 that writes its suggestions as text and only picks movies that exist in the catalog, plus a study of how the fine-tuning data shapes its accuracy and how evenly it serves different users.

Context
Graduation project, ITU
Published
EARL Workshop, CIKM 2026
Paper
arXiv:2611.03113
Authors
Furkan Yasir Goksu, Yaren Yılmaz, Şule Gündüz Öğüdücü

Built with

  • Llama 3 8B
  • LoRA
  • PyTorch
  • vLLM
  • MovieLens-1M
  • Prefix tree decoding

The problem

A language model can recommend movies by writing their titles, but it can also invent titles that don't exist or repeat itself. The way the training data is prepared, such as how prompts are worded, how titles are written or how users are sampled, also changes what the model learns and which users it serves well.

How it works

  1. Build each user's history from MovieLens-1M ratings of 4 or higher, in time order.
  2. Turn histories into training examples with many prompt templates, asking for the next movies.
  3. Fine-tune Llama-3-8B-Instruct with LoRA so it writes each title between special start and end tokens.
  4. Build a prefix tree over the tokens of all 3,883 catalog titles.
  5. While the model writes a title, only allow tokens that continue a real title, so every suggestion is in the catalog.

Findings

Writing titles the way MovieLens does, with the article at the end, gives better recommendations and a wider range of movies. It changes which token the model has to commit to first.

Models trained with different data mixes and losses end up very close to each other, so the loss function matters less than the data format.

Balancing training data by gender costs some accuracy, while adding movie knowledge keeps accuracy and makes recommendations the most even across user groups.
